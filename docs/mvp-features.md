# MVP機能一覧

## MVPの目的

最小の実用価値として、「個人でも使える」「クラス共有でも使える」「締切忘れを減らせる」状態を成立させる。

## MVP対象機能

### 1. 認証

- ユーザー登録
- ログイン
- ログアウト
- セッション維持

### 2. 個人課題管理

- 課題作成
- 課題編集
- 課題削除
- 締切設定
- 提出済み / 未提出切替
- 未提出一覧
- 提出済み一覧

### 3. 共有機能

- クラス / チーム作成
- 参加コードでクラス / チーム参加
- クラス / チーム退出
- 共有課題作成
- 共有課題閲覧

### 4. 通知

- 通知先メールアドレス設定
- 締切何日前に通知するか設定
- 通知の有効 / 無効切替
- 締切通知メール送信

### 5. 表示機能

- 課題一覧
- 締切順表示
- 緊急度表示
- カレンダー表示

### 6. PWA基礎

- マニフェスト
- インストール可能な基本構成
- モバイル表示最適化

## MVPに含めない機能

- 添付ファイルアップロード
- コメント / チャット
- 保護者アカウント
- 成績管理
- 課金
- 組織管理ダッシュボード
- 外部サービス連携
- 詳細分析
- ネイティブアプリ

## MVP完了条件

以下が一通り成立すれば MVP リリース可能と判断する。

1. ユーザーが登録してログインできる
2. 個人課題を登録し、提出済み管理できる
3. クラス / チームを作成し、他ユーザーが参加できる
4. 共有課題を登録してメンバーが確認できる
5. 締切通知メールが定期実行で送られる
6. スマートフォンで日常利用に耐える

## MVP以降の優先追加候補

### 優先度 高

- Web Push 通知
- 添付ファイル
- 課題の検索 / フィルタ
- 招待リンク方式

### 優先度 中

- コメント
- テンプレート課題
- ダッシュボード
- 期限超過レポート

### 優先度 低

- 組織全体管理
- 外部カレンダー同期
- AI補助機能
